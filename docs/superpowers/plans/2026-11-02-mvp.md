# Entre Nos MVP Implementation Plan

> For agentic workers: use task-based execution with verification and incremental commits; keep external integrations consent-gated.

**Goal:** Deliver a working local-first, installable mood, routine, meals, music, memory and challenge app for a long-distance couple.

**Architecture:** A static browser application persists metadata locally and uploaded photos in IndexedDB. Its production-ready SQL schema secures two-user shared records in Supabase with row-level security; cloud sync and OAuth connections are staged separately.

**Tech Stack:** HTML5, CSS3, ES2022, IndexedDB, localStorage, Web App Manifest, PostgreSQL with Supabase Auth/RLS/Storage.
