# Login Entre Nós

A implementação anterior foi consolidada com a revisão 0.3. O aplicativo oferece e-mail/senha, criação de conta, recuperação, link por e-mail para conta existente e login Google quando o provedor estiver habilitado.

A configuração e os critérios de validação estão em [CONEXOES.md](CONEXOES.md). O código não contém credenciais ativas e não declara contas conectadas antes da autorização.

O modo anterior de prévia sem login não abre os registros nesta versão. Dados antigos foram preservados e a conta autenticada pode exportá-los explicitamente, se forem seus, em Meu cantinho. Dados novos são separados por usuário no aparelho.
